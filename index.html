Instant Vercel Hosting & Running Steps

Host this website on Vercel for free in under 1 minute, or run locally on your machine.

1. Deploy to Vercel (1-Command)

Everything is pre-configured with vercel.json. Run this command in terminal:

Run in Terminal
# 1. Deploy immediately
npx vercel

# 2. Deploy to Production URL:
npx vercel --prod

You will get a live URL (e.g. https://genius-shoppy.vercel.app) that you can open on any phone or laptop!

2. Run Website Locally

You can run this website on your laptop instantly:

Python or Node
# Option 1: Python
python -m http.server 3000

# Then open:
http://localhost:3000

Test the real extension on Flipkart and Amazon.in:

  1. Download smartshopper_extension.zip and unzip it.
  2. Open Chrome and go to chrome://extensions/
  3. Enable Developer mode (toggle on top right).
  4. Click "Load unpacked" and select the extension folder!
